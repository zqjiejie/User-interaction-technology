# CampusMind 智伴校园小程序项目报告（中文版）

## 1. 项目简介

CampusMind 是一款面向高校学生的校园生活辅助微信小程序。项目围绕大学生日常学习生活中的高频需求展开，将日程管理、课程/任务查看、无边记、生活状态记录、番茄钟专注、发现页统计和周报复盘整合在一个移动端工具中，帮助学生完成“计划、行动、记录、反馈、调整”的闭环。

本项目选题属于人机交互领域中的移动交互、直接操纵、信息可视化与用户体验设计方向。与普通日历或待办工具相比，CampusMind 不只关注“把任务记下来”，也关注学生在一周内的学习、娱乐、运动、睡眠和专注状态，并通过发现页与周报把分散数据转化为可理解的反馈。

项目当前版本的核心定位为：

```text
校园日程管理 + 无边记记录 + 专注行动 + 生活状态周报
```

## 2. 目标用户与需求分析

目标用户主要是高校学生，尤其是同时面临课程、作业、考试、项目、社团、运动、娱乐和作息管理压力的学生群体。

大学生常见痛点包括：

| 用户痛点 | 具体表现 | CampusMind 的设计回应 |
| --- | --- | --- |
| 今日安排不清晰 | 课程、会议、作业、个人计划分散在不同工具中 | 首页默认展示今日日历和当日安排 |
| 新建任务成本高 | 复杂表单会让用户放弃记录 | 新建日程采用接近日历应用的轻量表单 |
| 月度规划不可见 | 列表视图难以观察安排密度 | 提供完整月历视图和日期浮层 |
| 临时想法难保存 | 灵感、课堂记录、日记容易散落 | 提供无边记入口 |
| 行动与计划脱节 | 有日程但缺少进入专注的操作 | 提供番茄钟选择和计时页面 |
| 数据无法复盘 | 记录后缺少阶段性反馈 | 发现页和周报页进行统计与可视化展示 |
| 隐私与 AI 权限敏感 | 日记、笔记等内容较私密 | 权限开关由用户控制，AI 读取需要授权 |

## 3. 程序结构与模块说明

项目目录为 `lifepilot-miniprogram`，采用微信小程序前端与微信云开发后端结合的结构。

### 3.1 前端结构

```text
lifepilot-miniprogram/
  miniprogram/
    app.js                    # 小程序启动、云环境初始化、登录状态同步
    app.json                  # 页面路由、窗口、tabBar 和组件框架配置
    app.wxss                  # 全局样式
    custom-tab-bar/           # 自定义底部导航
    pages/                    # 功能页面
    utils/                    # 通用工具、云函数调用、本地缓存、统计计算
    assets/                   # 图标、装饰图、底栏资源
```

前端主要页面包括：

| 页面 | 功能 |
| --- | --- |
| `login` | 登录与用户进入 |
| `home` | 今日日程、日期选择、日程列表、搜索/新增入口、无边记入口 |
| `calendar` | 月历视图、日期浮层、日程与无边记查看 |
| `discover` | 学习、运动、娱乐、睡眠概览与番茄钟入口 |
| `discoverModule` | 单一生活模块的趋势与明细 |
| `mine` | 个人资料、目标、功能入口、隐私授权 |
| `search` | 日程、课程和笔记搜索 |
| `scheduleAdd` | 新建/编辑日程、重复规则、提醒、语音/文本解析入口 |
| `schedule` | 课程表与日程统一管理 |
| `record` / `recordModule` | 生活记录总览与模块录入 |
| `report` | 周报统计、建议、AI 周报入口 |
| `pomodoroSelect` / `pomodoroTimer` / `pomodoroList` | 番茄钟选择、计时和历史 |
| `boundlessNote` / `noteList` | 无边记编辑和列表 |
| `sport` / `entertainment` / `sleep` | 生活数据详情页面 |

### 3.2 后端结构

```text
cloudfunctions/
  userService/          # 用户登录、初始化、资料更新
  scheduleService/      # 日程创建、查询、搜索、解析
  noteService/          # 无边记创建、查询、删除
  recordService/        # 生活记录、番茄钟、概览、基础周报
  reminderService/      # 日程提醒扫描与订阅消息发送
  reportService/        # AI 周报生成
  speechService/        # 语音识别
  ocrCourseService/     # 课表图片 OCR 与课程解析
```

### 3.3 技术栈

| 层级 | 技术/框架 | 作用 |
| --- | --- | --- |
| 小程序前端 | WXML / WXSS / JavaScript | 页面渲染、交互和本地缓存 |
| 组件框架 | glass-easel | 小程序组件框架 |
| 云开发 | 微信云开发 | 云函数、云数据库、云存储 |
| 云函数运行时 | Node.js + wx-server-sdk | 用户、日程、记录、笔记、提醒和报告服务 |
| AI 解析 | DeepSeek API | 自然语言日程解析、AI 周报生成 |
| OCR/ASR | 腾讯云 SDK | 课表图片识别、语音识别 |
| 本地缓存 | wx.getStorageSync / wx.setStorageSync | 离线降级、草稿和本地记录 |

## 4. 已实现需求与功能

### 4.1 登录与个人资料

程序支持用户进入小程序后创建或读取用户信息。登录状态会写入本地缓存，便于用户下次快速进入。个人资料页支持学校、专业、年级、学习目标、运动目标、睡眠目标等信息展示与管理，并提供 AI 权限相关开关。

### 4.2 今日日程

今日日程是默认首页。用户可以直接查看当前月份、当前选中日期和该日安排。日期下方使用圆点标记是否存在日程。用户可以点击日期切换当天安排，也可以从顶部进入搜索页或新增日程页。日程列表支持左滑删除和点击编辑。

### 4.3 新建与编辑日程

日程表单支持标题、地点、全天开关、开始日期、开始时间、结束日期、结束时间、重复规则、重复结束日期、提醒、URL、备注和长文本输入。系统会校验标题是否为空、结束时间是否早于开始时间等常见错误。重复日程支持“仅本次”和“全部重复日程”的修改或删除。

### 4.4 搜索

搜索页支持用户按照标题、课程名、地点、教室、日期、备注等关键词查找事项。搜索结果展示标题、时间、日期、地点和分类标签，并对结果进行标准化和去重。

### 4.5 日历视图

日历页以月历网格展示整月安排。用户可以切换月份，点击某一天打开底部浮层。浮层展示该日详细日程、无边记和灵感记录，并支持拖拽调整高度和左右切换内容。

### 4.6 无边记

无边记用于记录课堂灵感、日记、临时想法和补充材料。用户可以从今日页、日历页或我的页进入无边记，支持文本记录和附件扩展。无边记内容可以按日期与日程共同出现在复盘流程中。

### 4.7 生活记录

生活记录支持学习、运动、娱乐、睡眠四类模块。用户可以记录标题、时长、开始时间、结束时间和备注。记录会进入本地统计，并影响发现页和周报页的数据展示。

### 4.8 发现页与模块详情

发现页展示本周学习、运动、娱乐和睡眠四类数据概览，包括总时长、活跃模块、周趋势和模块卡片。点击模块后进入详情页，查看该模块的趋势图、今日时长、本周累计和记录明细。

### 4.9 番茄钟专注

番茄钟模块支持用户选择专注类型或关联任务，进入计时页后可开始、暂停、继续和结束。结束后的专注记录会进入统计，用于发现页和周报页复盘。

### 4.10 周报复盘

周报页汇总本周学习、娱乐、运动、睡眠、日程和专注记录，展示基础统计、趋势和建议。若配置 AI 服务，还可以调用 AI 生成结构化周报，包括总结、亮点、问题、建议和下周重点。

### 4.11 课表图片导入

课表图片导入功能通过 OCR 识别图片文字，并可结合 AI 将课表文本解析为课程结构。用户确认后，课程可以写入本地或云端日程体系。

### 4.12 语音日程输入

语音服务支持将用户输入的语音转换为文本，并进一步调用日程解析能力，提取标题、时间、地点和提醒等字段。该能力需要配置腾讯云 ASR 密钥。

### 4.13 提醒服务

提醒服务通过云函数定时扫描即将到期的日程，并结合微信订阅消息发送提醒。成功发送后会标记提醒状态，避免重复发送。

## 5. 人机交互设计亮点

### 5.1 今日优先的信息组织

程序默认进入今日日程页，把用户最关心的“今天要做什么”放在第一屏。相比复杂仪表盘，这种结构更符合大学生短时间打开小程序快速确认安排的场景。

### 5.2 直接操纵

项目使用点击、滑动、拖拽等直接操纵方式：

- 首页点击日期切换当天安排。
- 首页上下滑动切换月份。
- 日程项左滑删除。
- 日历页点击日期打开浮层。
- 日历浮层上下拖动改变高度。
- 浮层内部左右切换内容。
- 生活记录通过短表单和时间选择完成。

这些交互减少了深层菜单和复杂表单，使用户能够直接作用于屏幕上的对象。

### 5.3 数据可视化与复盘

发现页和周报页将学习、娱乐、运动、睡眠和专注记录转化为趋势、统计和建议。用户不只是在“记录数据”，也可以通过图表理解自己的生活节奏。

### 5.4 隐私与用户控制

AI 读取日记、无边记和周报数据属于较敏感能力，因此项目将 AI 权限放在用户可控制的位置。AI 结果不会直接覆盖用户输入，而是作为辅助建议出现。

## 6. 程序优点

1. 功能场景贴近大学生日常，覆盖课程、任务、专注、记录和复盘。
2. 首页以今日为中心，主流程清晰，降低打开后的认知负担。
3. 自定义底部导航只保留四个一级入口，避免功能堆叠。
4. 日历、浮层、左滑删除、番茄钟等交互符合移动端使用习惯。
5. 本地缓存和云端服务结合，云函数不可用时仍有一定降级能力。
6. 后端模块拆分清晰，用户、日程、记录、笔记、提醒、报告等职责明确。
7. 为 AI 周报、语音识别、课表 OCR、订阅提醒等增强能力预留了接口。
8. 周报和发现页体现了信息可视化思想，能把记录转化为反馈。

## 7. 程序缺点与当前限制

1. 功能数量较多，若用户首次使用，可能需要一定时间理解各入口之间的关系。
2. AI 周报、语音识别、OCR 和提醒服务依赖外部环境变量，部署不完整时无法稳定演示。
3. 部分功能依赖本地缓存与云端同步，复杂场景下需要继续验证数据一致性。
4. 课表 OCR 可能出现识别错误，需要用户确认流程来避免错误写入。
5. 搜索、无边记、番茄钟等二级页面需要持续强化返回和退出路径。
6. 如果用户没有持续记录生活状态，周报的数据价值会下降。
7. 重复日程的单次修改、全部修改、单次删除、全部删除逻辑较复杂，需要重点测试。

## 8. 改进方向

第一阶段应优先提升稳定性和主流程完成度：

- 完善首次登录资料录入与退出登录流程。
- 统一搜索页、番茄钟页、无边记页等二级页面的返回方式。
- 建立今日页、日历页和搜索页共享的日程索引，减少重复结果。
- 强化日程重复规则、删除规则和编辑规则的边界测试。
- 优化空状态、错误状态和保存反馈。

第二阶段可增强智能能力：

- 完善自然语言日程解析。
- 增强语音创建日程能力。
- 完善课表 OCR 导入后的用户确认界面。
- 接入稳定的 AI 周报生成流程，并加入加载状态和失败降级。

第三阶段可扩展协作与长期使用能力：

- 增加倒数日、习惯打卡和日程模板。
- 支持学习小组或项目小组共享计划。
- 支持导出周报或生成分享摘要。
- 增加更多可访问性优化，例如更明确的图标说明、触控区域和视觉反馈。

## 10. 可用性评估方案

除功能测试外，还应进行轻量用户测试。建议邀请 3 到 5 名高校学生完成以下任务：

1. 找到今天下午的安排。
2. 新增一个明天下午 3 点的组会日程。
3. 在日历中查看某一天的详细记录。
4. 新建一条无边记，记录一段课堂灵感。
5. 记录今天的学习、运动、娱乐和睡眠情况。
6. 开始一次 25 分钟番茄钟专注。
7. 找到本周周报，并说出本周最需要调整的生活状态。
8. 首次登录后填写并保存基本信息。
9. 从搜索页、番茄钟页和无边记页返回上一页。

评价指标如下：

| 指标 | 观察方式 |
| --- | --- |
| 完成率 | 用户能否独立完成任务 |
| 完成时间 | 每个任务耗时是否过长 |
| 错误次数 | 是否频繁点错入口、误删或迷路 |
| 入口理解度 | 用户能否理解四个底部导航含义 |
| 表单负担 | 新建日程和生活记录是否显得繁琐 |
| 反馈清晰度 | 保存、删除、搜索后用户是否知道结果 |
| 复盘价值 | 用户是否认为周报建议有帮助 |
| 退出可见性 | 用户是否能快速找到返回和退出入口 |
| 数据一致性 | 同一数据在首页、日历、搜索和周报中是否一致 |

## 11. 项目原创性

CampusMind 的原创性主要体现在三个方面：

1. 场景整合：项目不是单纯的日历、待办或番茄钟，而是围绕大学生校园生活建立连续闭环。
2. 交互整合：项目将日历点击、浮层拖拽、左滑删除、模块化记录、番茄钟计时等移动端交互统一到小程序中。
3. 反馈整合：项目通过发现页和周报，把原本分散的学习、娱乐、运动、睡眠和专注数据转化为阶段性反馈。

## 12. 结论

CampusMind 已经形成一个较完整的校园生活管理小程序原型。它以今日日程为入口，连接日历、搜索、无边记、生活记录、番茄钟和周报复盘，符合人机交互课程中关于直接操纵、信息组织、反馈机制和用户体验评估的要求。

从课程项目评分角度看，程序部分具有多个可演示功能，包括登录、日程、新建、编辑、删除、搜索、日历、无边记、生活记录、发现页、番茄钟、周报、语音、OCR 和提醒服务。报告部分覆盖了程序简介、结构模块、已实现需求、优缺点、改进方向和完整测试栏目。后续如果需要提交英文报告，可以在本中文版基础上翻译并进一步补充实际测试结果截图。
